# 🚀 Codomax Web Development Internship - Day 1 to Day 12 Tasks

This repository contains all the tasks completed during the **Codomax Web Development Internship**. Instead of creating separate files for each task, all the concepts from **Day 1 to Day 12** have been integrated into a **single responsive web application**.

## 📌 Project Overview

The project demonstrates the practical implementation of fundamental web development concepts using **HTML**, **CSS**, and **JavaScript**. It showcases responsive design, interactive UI elements, form validation, navigation, and modern webpage layouts.

## ✨ Features

- Responsive Navigation Bar
- Hero Section
- About Section
- Skills Section
- Projects Showcase
- Resume Download Section
- Education Section
- Contact Form
- Interactive Buttons
- Smooth Scrolling
- Form Validation
- Responsive Design
- Modern User Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Google Fonts

Simply open the `portfolio.html` file in your browser.
